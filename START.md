## Files

- `revenue_app.pyw` — 1200x800 dark dashboard: project switcher, 6 KPI cards, 12-month bar chart, cost panel, current-month profit/insights, 60s auto-refresh, F5, Ctrl+,, Neon/Vercel detail dialogs and settings

- `vercel_billing.py` — Vercel FOCUS charges, Pro credit, invoices
- `run.bat`, `icon.png`, `icon.ico`

## Config / secrets

`config.json` sits beside these scripts and is intentionally **gitignored**. It contains the Lexlab revenue API key, Neon API key and Vercel token, plus project URLs. Never commit it and never paste its values into code or logs. Environment overrides are supported:

- `REVENUE_API_URL`, `REVENUE_API_KEY` (legacy `LEXLAB_*` fallback)
- `NEON_API_KEY`, `NEON_ORG_ID`, `NEON_PROJECT_IDS`, `NEON_USD_MNT`
- `VERCEL_API_TOKEN` / `VERCEL_TOKEN`, `VERCEL_TEAM_ID`, `VERCEL_TEAM_SLUG`, `VERCEL_USD_MNT`
